# Exercism TypeScript Solutions

Welcome to my repository dedicated to tracking my progress, practice,and problem-solving journey on [Exercism](https://exercism.org/).
I use this space to master **TypeScript**, deepen my understanding of static typing, and practice writing clean, algorithmic code.


---

## Learning Objectives

* Master core TypeScript concepts (Interfaces, Types, Generics, Enums).
* Implement efficient data structures and algorithms (e.g., Linked Lists, Matrices, Trees).
* Write highly readable, self-documenting code utilizing strictly-typed principles.
* Apply Test-Driven Development (TDD) using the built-in testing suites provided by Exercism.

##  Repository Structure

 Here are few examples, each directory represents a specific challenge or track component solved natively in TypeScript:

* `typescript/linked-list/` — Implementation and manipulation of sequential data structures.
* `typescript/resistor-color/` - Mapping color bands to their digital values using arrays and lookups.
* `typescript/two-fwr/` - Handling conditional string formatting and default function parameters.
* `typescript/leap/` — Implementing boolean logic constraints to determine leap years.
* `typescript/space-age/` — Calculating orbital periods across different planets using floating-point math and type constraints.

##  Local Setup & Running Tests

Exercism exercises come with pre-configured test suites. To run any solution locally:

1. Navigate to the specific exercise directory, for example:
   ```bash
   cd typescript/linked-list
   ```

2.Install the necessary development dependencies (you will have to do this at each exercise you download):
```bash
yarn corepack install
```

3. After implementing your solution, to run the test:
```bash
yarn corepack test
```
